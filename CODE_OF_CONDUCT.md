# Code of Conduct

This project expects respectful, professional, and evidence-based collaboration. Contributors of
all backgrounds and experience levels are welcome.

Harassment, discrimination, personal attacks, doxxing, publication of private device data, or
intentional distribution of unsafe builds is not accepted. Technical disagreements should focus on
reproducible behavior, redacted logs, code, and tests.

Maintainers may edit or remove content that violates these expectations and may restrict accounts
that repeatedly disrupt the project. Report conduct concerns privately through the repository
owner's GitHub contact channel.
